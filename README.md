# 분양한눈

청약홈·LH의 공식 공공데이터를 한 흐름으로 정규화해 지역별 신규 공고와 주요 일정을 알려주는 한눈서비스 PWA입니다.

## 로컬 실행

```bash
npm run collect  # DATA_GO_KR_SERVICE_KEY 필요
npm run check
python3 -m http.server 4173 -d dist
```

API 키가 없거나 수집이 실패하면 마지막 검증 데이터 또는 예시 데이터로 앱 셸을 유지하며, 예시 데이터임을 화면에 표시합니다.

## 데이터 원칙

- 한국부동산원 청약홈 API: 민간분양, 무순위, 오피스텔·민간임대 등
- LH 분양임대공고 API: 분양주택·신혼희망타운·임대주택
- SH: 공식 공고와 공식 문자 알리미로 연결하며, 비공식 스크래핑 결과를 사실 데이터로 합치지 않음
- 원문 링크와 수집 시각을 보존하고, 변경된 일정은 새 값으로 덮지 않고 변경 이벤트로 알림 대상으로 분류

자세한 설계는 `docs/DATA-AND-NOTIFICATION.md`를 참고하세요.
