# 분양한눈 제품 경계

## 사용자가 해결하는 일

`어디에 어떤 신규 분양이 나왔고, 예산·규모·입주 시기를 비교할 때 무엇을 먼저 볼 것인가`를 해결합니다.

## 포함

- 민간분양, 공공분양, 무순위·잔여세대, 임의공급, 오피스텔
- 지역·분양 유형 탐색, 분양가·전용면적·세대수·입주예정 비교
- 공식 공고 일정, 관심단지 저장, Android 신규 단지·마감 알림
- 공식 데이터 출처·갱신 상태와 광고성 상담 정보 배제

## 제외·연결

- 공공·민간 임대 전체 탐색, 청약 순위·자격 준비, 마감 중심 실행은 `청약한눈`으로 연결합니다.
- 상담 신청형 광고 단지를 공식 공고 목록에 섞지 않습니다.
- 분양가나 청약 자격, 당첨 가능성을 계산하거나 보장하지 않습니다.

## 기술 격리

- URL/PWA: `/bunyanghannun/`, PWA ID `/bunyanghannun/`, 캐시 `bunyanghannun-shell-*`
- 웹 저장 키: `bunyanghannun:*`
- Android: `net.softm.bunyanghannun`, `BunyangNative`, `BunyangHannunAndroid/1.0`
- 광고: AdFit 매체 `NKm`; 청약한눈 `NKw` 단위 재사용 금지
