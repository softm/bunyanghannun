# 청약한눈 제품·데이터 조사

조사일: 2026-11-22 (KST)

## 경쟁 서비스에서 가져온 인사이트

### 분양알리미 앱·웹

- 청약홈·LH·SH를 한곳에 묶는 것이 기본 기대치다.
- 홈에서 `오늘`, `예정`, `모집중`, `무순위`, `공고` 상태를 즉시 나누고 월간 캘린더와 지역 필터를 함께 제공한다.
- 공고 카드에는 지역, 세대수, 면적, 가격을 먼저 보여 주고 지도·캘린더·관심·MY로 탐색을 분리한다.
- 상업 분양 상담 콘텐츠와 공식 청약 공고는 사용자가 오인하지 않도록 명확히 구분해야 한다.

### 공공주택알리미

- LH·SH·GH·HUG 등 기관 탭, 전국 지도, 마감임박순, 관심 공고, 공고 캘린더가 핵심이다.
- 공고문을 앱 안에서 읽고, 공급형별 정보·주거복지·공고별 커뮤니티까지 연결한다.
- 청약한눈은 첫 버전에서 지도보다 일정과 준비 행동을 우선하고, 출처·갱신 기준·원문 연결을 더 선명하게 제공한다.

### SH 청약공고 알리미

- 주택임대·주택분양 공고 후 접수일 이전에 카카오 알림톡을 보내고, 수신 불가 시 SMS를 사용한다.
- 신청은 해당 연도에만 유효하며 연락처 변경·스팸 방지를 이유로 매년 갱신한다.
- 청약한눈도 알림 조건을 영구 방치하지 않고 1년에 한 번 재확인하도록 설계한다.

   - 접수 시작·종료, 특별공급, 1·2순위, 당첨자 발표, 계약 기간, 입주 예정월을 알림 일정으로 사용
2. LH 분양임대공고문 조회 서비스
   - 공공데이터포털 데이터 ID `15058530`

   - 임대주택·분양주택·주거복지·신혼희망타운 공고를 보강
3. SH 공고 및 공지
   - 공개 게시판의 주택분양·주택임대 공고를 보강
   - 구조 변경에 취약하므로 수집 실패를 전체 서비스 실패로 간주하지 않고 원문 바로가기를 유지

## 알림 전달 구조

- GitHub Actions가 6시간 간격으로 공식 데이터를 수집하고 정규화된 `data/notices.json`을 배포한다.
- 웹은 사용자가 다시 열었을 때 이전 목록과 비교해 새 관심 공고를 알려 주며, 접수 일정을 `.ics`로 내보낸다.
- Android는 WorkManager가 네트워크 연결 시 약 6시간마다 같은 JSON을 확인하고 신규 공고, D-3, D-1, 당일 마감 알림을 로컬에서 생성한다.
- 공고 날짜가 변경될 수 있으므로 알림과 카드에는 항상 `기관 원문에서 최종 확인`을 표시한다.
