# 데이터·알림 설계

## 공식 원천

1. 한국부동산원 청약홈 분양정보 조회 서비스(공공데이터포털 15098547, 실시간)
2. LH 분양임대공고문 조회 서비스(공공데이터포털 15058530, 실시간)
3. SH 인터넷청약시스템 공고와 SH 공식 알리미(링크 제공)

## 정규화

공고는 `source + sourceId`로 식별하며 이름, 지역, 주소, 공급유형, 모집공고일, 접수 시작·종료, 당첨발표일, 계약기간, 입주예정월, 공급세대수, 원문 URL을 저장합니다. 원천끼리 같은 단지를 임의로 합치지 않고, 주소·일정·공고번호가 충분히 일치할 때만 관련 공고로 표시합니다.

## 알림 이벤트

- 신규 공고 등록 즉시
- 관심지역 공고 등록
- 접수 7일·3일·1일 전과 접수 당일
- 접수 마감 당일
- 당첨자 발표 당일
- 원천에서 일정 또는 상태가 변경된 경우

웹 PWA의 알림 구독은 HTTPS Push 백엔드가 준비된 뒤 활성화합니다. Android 앱은 FCM 토픽(지역·공급유형)과 단지별 구독을 사용합니다. 서버는 마지막 스냅샷과 새 스냅샷을 비교해 중복 없는 `eventId`를 생성하며, 원문에서 사라진 공고는 삭제 알림 대신 확인 필요 상태로 둡니다.
